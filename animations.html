CSS Animations

Two custom CSS animations are implemented across the site to enhance visual feedback and page transitions:

1. Logo Spin (.nav-logo)

  • Effect: Hovering over the logo in the top-left navigation triggers a 360° rotation.
  • Demonstration: See it in action on the Homepage navigation bar.

2. Fade & Lift on Load (.fade-in)

  • Effect: The main content block on every page smoothly fades in and lifts upward on page load.
  • Demonstration: Refresh this page, or visit the Hometown page to view the transition.
Accessibility Note: Both animations adhere to web accessibility guidelines by respecting the prefers-reduced-motion media query, disabling movement for users with reduced motion enabled in their OS.
