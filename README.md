# My first website: Personal Portfolio Site
A responsive, multi-page website built with semantic HTML5 and external CSS3 as part of Swinburne University of Technology's COS10005 Web Development unit. 

The site showcases personal background, achievements, hometown history, custom CSS animations, and an interactive review/feedback form.
## 📁 Repository Structure

```text
├── index.html          # Portfolio Homepage
├── aboutme.html        # Personal background & timetable
├── hometown.html       # Overview of hometown history & media
├── achievements.html   # Key milestones, credentials, & photo gallery
├── animations.html     # Technical animation breakdown & review/feedback form
├── style/
│   └── style.css       # Combined external stylesheet for all pages
└── README.md           # Project documentation
